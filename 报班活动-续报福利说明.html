限时优惠与续报福利说明

两套政策并行：限时活动期间报班享学费折扣（可折上折）；只要续报进阶，即赠送三门配套课程 （原理课、录播课、大赛样例课）。折扣管学费，赠课管续报福利。

限时优惠活动：8.5 折 续报进阶：8 折 可折上折约 6.8 折 续报即送三门课

一、课程进阶路径（先修关系）

课程按「基础 → 衔接 → 实战」分层，先修满足后再报下一层更稳妥。

基础层
零基础 / 未学过 Python → C01 Python入门班 原价 1280 元 （4 周 / 8 次课，零基础可报）
路径 A：数据 / 传统建模
C01 → C02 Python数据分析班 3680 元 （建议有入门基础）→ C04 机器学习项目班 6980 元 （须已学数据分析）
路径 B：大模型 / Agent
C01 → C05 大模型应用开发班 5280 元 （须有入门基础）→ C06 AI智能体实战班 7580 元 （建议先完成大模型班）

二、限时优惠活动（学费折扣）

1. 限时优惠：8.5 折

  • 活动期间新报任意在售课程，学费按原价 8.5 折结算。
  • 零基础学员限时活动期间报 C01 入门班，同样享受 8.5 折。

2. 入门结业续报进阶：8 折

  • 已完成 C01 Python入门班 后，续报进阶课程（C02 / C05，以及后续 C04 / C06）可享 8 折。

3. 折上折（限时活动 + 续报同时满足）

若学员在限时活动期间续报进阶，且已满足「入门结业续报」条件， 可先享续报 8 折，再叠加限时活动 8.5 折，即实际约为原价的 8 × 8.5 = 6.8 折（折上折）。
  • 仅「限时活动期间新报、非续报」：只享受 8.5 折。
  • 「非限时活动期间、入门后续报进阶」：只享受 8 折。
  • 「限时活动期间 + 入门后续报进阶」：可折上折（约 6.8 折）。

4. 零基础一次性打包（同样折上折 + 送三门）

零基础学员若一次性报名，以下方案均享受整单折上折（约 6.8 折），并赠送原理课、录播课、大赛样例课三门：
  • 入门 + 任意一门进阶：C01 +（C02 / C04 / C05 / C06 任选一）
  • 整条路径 A：C01 + C02 + C04（数据 / 传统建模）
  • 整条路径 B：C01 + C05 + C06（大模型 / Agent）

费用参考见资料库表「打包报名费用」工作表（如入门+数据分析原价合计 4960 → 约 3373）。

三、续报福利：只要续报就送三门课

只要学员续报进阶课程（C02 / C05 / C04 / C06 任一），即赠送以下三门配套课程。 零基础一次性打包（入门+进阶 / 路径A / 路径B）同样送这三门。 与限时优惠活动学费折扣相互独立：打折管学费，赠课跟续报/打包走。
① 原理课 配套核心概念 / 算法或大模型原理精讲，帮助打牢理论基础。
② 录播课 重点章节回放与拓展专题，方便复习补课、按自己节奏反复观看。
③ 大赛样例课 竞赛 / 项目样例包（题目思路、代码骨架、提交规范参考），服务实战与作品集。
  • 触发条件：正式续报任一进阶正课（不要求必须在限时优惠活动期间）。
  • 交付：报名确认后由教务开通，三门一并赠送，不另收费。
  • 限时优惠活动期间续报：学费可走折上折，同时仍送三门课。
